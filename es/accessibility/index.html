Declaración de accesibilidad

Pinnacle EDS se compromete a que este sitio web pueda ser utilizado por todas las personas, incluidas las personas con discapacidad. Buscamos cumplir las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1, nivel AA.

Lo que hacemos

  • Todas las páginas pueden usarse solo con el teclado, con indicadores de foco visibles.
  • Las páginas usan encabezados y regiones para que los usuarios de lectores de pantalla puedan navegar con facilidad.
  • El texto y los controles cumplen las relaciones mínimas de contraste de color, y el texto puede ampliarse sin perder contenido.
  • Las imágenes tienen alternativas de texto y los formularios tienen etiquetas y mensajes claros.
  • El sitio se ofrece en varios idiomas, con un diseño de derecha a izquierda para el árabe.
  • Las animaciones se pueden pausar y se detienen automáticamente si tu dispositivo está configurado para reducir el movimiento.

Limitaciones conocidas

Algunas traducciones son borradores que aún están siendo revisados por hablantes nativos.

Comentarios y ayuda

Si tiene dificultades para usar alguna parte de este sitio o necesita la información en otro formato, escriba a info@pinnacleeds.com. Describa la página y el problema. Procuramos responder en un plazo de cinco días hábiles.
